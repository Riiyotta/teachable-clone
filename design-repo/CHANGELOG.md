# Changelog

## 1.0.0 (2026-10-27)

First build, from scratch, against the current clone (18 served routes, all mounted).

- Tokens parsed from the clone's config and stylesheet with real `path:line` citations and the matched text on that
  line; semantic/component layers, a single light theme, `tokens/llm` catalog + policy + allowlist.
- 56 section contracts with a provenance (`source`) / taxonomy (`semantic`) split, measured budgets (counts only),
  asset roles, motion patterns, responsive notes, 1440/390 heights and retrieval eligibility.
- 10 templates by page purpose; every route mapped once; compatibility graph agreeing with the validator.
- PageSpec `mode` (reference | generated) with generated-mode leakage rules; hashed identity/copy registry so no source
  copy or real names are stored; asset availability and policies pinned in code.
- Wrapper-height gate on measured 1440 heights; adversarial suite and scratch-copy drift proofs.
- Groundwork corrections recorded in `extraction/measured-values.json` (`groundworkCorrections`).
